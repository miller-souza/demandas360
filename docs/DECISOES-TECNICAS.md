# Decisões técnicas

- **Flask:** suficiente para uma API pequena, com baixa complexidade operacional.
- **JSON:** facilita execução local e inspeção dos dados demonstrativos.
- **Filtros no backend:** mantém a API reutilizável por outros clientes.
- **JavaScript nativo:** evita dependências de framework para uma interface de escopo enxuto.
- **Dados sintéticos:** permite demonstração sem expor dados de terceiros.
